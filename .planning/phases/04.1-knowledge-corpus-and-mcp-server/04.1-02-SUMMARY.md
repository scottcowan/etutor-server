# Phase 04.1 Plan 02: Corpus Index + Keyword Search Summary

**In-memory filesystem index builder (`build_index()`) and plain keyword search (`search_corpus_impl()`) for the knowledge corpus, both pure functions with zero MCP/stdio coupling, TDD'd against a synthetic fixture corpus.**

## Performance

- **Duration:** 25 min
- **Tasks:** 2 completed
- **Files modified:** 10 (9 created, 1 modified)

## Accomplishments
- `build_index(root)` scans a corpus root's `wiki/` tree via `python-frontmatter`, always returns all four buckets (topics/sources/experiments/people) even when empty, and silently skips `index.md`
- `search_corpus_impl(index, query, subject?, level?, type_?)` does case-insensitive substring matching over content + tags/topic_ids, applying metadata filters before the substring check (structurally avoids path-traversal risk per research's Security Domain note — lookups never construct filesystem paths from caller input)
- Synthetic fixture corpus (2 topics, 1 source, 1 experiment, 1 index.md) under `tests/fixtures/corpus/` so tests never depend on the real, evolving `docs/corpus/` content
- `mcp>=2.1.0` and `python-frontmatter>=1.3.0` added to `requirements.txt` and installed into the project `.venv`
