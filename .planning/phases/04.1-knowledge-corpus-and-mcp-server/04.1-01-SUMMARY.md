# Phase 4.1 Plan 01: Corpus Scaffold and Content Migration Summary

Scaffolded the `docs/corpus/` L0-L3 directory tree per D-04 and migrated all 9 pre-existing content files (3 source-material essays/research docs, 6 experiment guides) into it with `git mv` history preservation and schema-correct frontmatter, closing the CORPUS-02 content-migration gap ahead of the MCP server work in later plans.

## What Was Built

**Task 1 — Directory scaffold.** Created the full `docs/corpus/` tree: `raw/`, `source/`, `summary/`, `wiki/topics/`, `wiki/people/`, `wiki/sources/`, `wiki/experiments/`. Added `.gitkeep` to directories left empty by this plan (source, summary, topics, people — populated by later plans). **Task 2 — Source material migration.** `git mv`'d all 3 files from `docs/wiki/source-material/` to `docs/corpus/wiki/sources/`, preserving git history (verified via `git log --follow`). Prepended D-10 YAML frontmatter (title, type, source_url, author, captured, topic_ids, level, prerequisite_topics, curation_note) to each, derived from each file's existing "Curriculum Relevance" table and header metadata. All `topic_ids` were cross-checked against `services/curriculum.py` before writing. Removed the now-empty `docs/wiki/` tree.

**Task 3 — Experiment guide migration.** `git mv`'d all 6 files from `docs/experiment-guides/` to `docs/corpus/wiki/experiments/`, preserving history. Prepended D-07 YAML frontmatter (topic_ids, min_age, flagged_dangerous, equipment, safety_notes, level) to each, with `flagged_dangerous` reasoning documented as an inline YAML comment per the plan's threat-model mitigation requirement. Body content left completely unchanged. Removed the now-empty `docs/experiment-guides/` directory.
