## MCP Server Design

| Option | Description | Selected |
|--------|-------------|----------|
| Separate stdio process | Python script registered in .claude/settings.json | ✓ (v1) |
| Embedded in FastAPI as HTTP MCP | /mcp/* endpoints | deferred |

**User's choice:** stdio process for v1. Noted: if Gemma 4 12B (no native MCP) is used, tool calls would go through the inference loop instead. Deferred to Phase 6.

**Tools selected:** get_topic, list_sources, search_corpus, get_experiments (all four), plus list_topics.

| Option | Description | Selected |
|--------|-------------|----------|
| Safety gate (hard min_age) + depth gate (prereq-based) | Two independent gates | ✓ |
| Just prereqs — age implicit in year_groups | One gate | |

**User's choice:** Two gates, but permissive — "be permissive with the age gating as long as they've done the prereqs." Only `flagged_dangerous: true` experiments get a hard age lock.
