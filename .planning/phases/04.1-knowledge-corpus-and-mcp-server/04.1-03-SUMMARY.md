# Phase 04.1 Plan 03: MCP Tool Implementations + Topic-ID Drift Validator Summary

**All 5 locked D-13 MCP tool behaviors (get_topic, list_sources, search_corpus, get_experiments, list_topics) implemented as plain, transport-decoupled Python functions with structurally path-traversal-safe index lookups, plus a standalone topic-ID drift validator (`find_mismatches`) diffing corpus filenames against `services/curriculum.py`.**

## Performance

- **Duration:** 20 min
- **Tasks:** 2 completed
- **Files modified:** 5 (4 created, 1 modified)

## Accomplishments

- `services/corpus_mcp/tools.py` implements `get_topic_impl(index, topic_id, level=None)`, `list_sources_impl(index, topic_id, type_=None)`, `get_experiments_impl(index, topic_id, min_age=None)`, `list_topics_impl(index, subject=None)`, plus a thin re-export of `search_corpus_impl` from `search.py`
- `get_topic_impl`'s `level` parameter splits page content on `## {level} ` heading boundaries and returns only the matching section
- `get_experiments_impl` implements D-06's dual gate: dangerous experiments are excluded when `min_age` is below the entry's own `min_age` (hard gate), while non-dangerous entries pass through regardless of `min_age` (permissive gate) — verified against two fixture experiments (one dangerous, one not)
- A deliberately malicious `topic_id` (`"../../../etc/passwd"`) passed to `get_topic_impl` returns the same not-found error dict as any ordinary missing key — confirmed structurally safe by `grep -n "Path(" services/corpus_mcp/tools.py` matching only a docstring comment, never a call site
- `services/corpus_mcp/validate_topic_ids.py` implements `find_mismatches(corpus_topics_dir, valid_ids) -> {"orphans": [...], "missing": [...]}` via set difference, ignoring `index.md`, plus a `main()` CLI entry point (`python -m services.corpus_mcp.validate_topic_ids`) that imports the real `CURRICULUM`, prints orphan/missing counts, and exits non-zero only on orphans (missing is expected/non-fatal — pilot-subject scope per D-05/04.1-05)
- Ran the CLI against the real (not-yet-populated) `docs/corpus/wiki/topics/` tree: 0 orphans, 975 missing (expected — corpus content itself is 04.1-05's job), exit code 0
