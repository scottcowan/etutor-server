# Phase 4 — UI Design Contract

> Visual and interaction contract for the parent dashboard. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 04-CONTEXT.md (D-01 to D-19), 04-RESEARCH.md, web/parent/templates/dashboard.html (live codebase).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — inline CSS, no component library |
| Preset | not applicable |
| Component library | none |
| Icon library | none — Unicode emoji used sparingly in headings only |
| Font | `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |

**Rendering approach:** Server-rendered Jinja2 HTML + HTMLResponse. No JS framework. Interactive accordion uses native `<details>/<summary>` HTML elements — zero JS required.

---

## Views in Scope

| View | Route | Description |
|------|-------|-------------|
| Login | `/parent/login` | Single passphrase field; no username; white-card centred layout |
| Dashboard overview | `/parent` | Child card + recent alert count + session list preview |
| Child profile + mastery map | `/parent/children/{child_id}` | Inline profile editor form + subject accordion below |
| Session replay | `/parent/sessions/{session_id}` | Turn-by-turn Q&A list, read-only |
| Alert feed | `/parent/alerts` | Chronological alert list, last 30 days |

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, mastery dot margin, badge vertical padding |
| sm | 8px | Compact inner padding, tag gaps, submit button vertical padding |
| md | 16px | Default element spacing, form field margin, header padding vertical |
| lg | 24px | Card padding, section margin-bottom, submit button horizontal padding |
| xl | 32px | Main content top/bottom margin |
| 2xl | 48px | Between major page sections |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Header horizontal padding: 32px (matches existing `padding: 1rem 2rem` pattern)
- Main content max-width: 900px centred (matches existing `max-width: 900px; margin: 2rem auto`)
- Session replay turn padding: 12px horizontal (matches existing `0.75rem` — acceptable deviation for dense turn list)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Default paragraph, turn answer text, form labels, safety flag marker |
| Label | 14px | 400 | 1.4 | Meta text, timestamps, reading level, interests, alert badge text |
| Heading | 18px | 600 | 1.2 | Section headings (h2), card headings (h3), accordion summary subject name |
| Display | 20px | 600 | 1.2 | Page-level header title (h1 in `<header>`) |

Font sizes derived from existing `dashboard.html`: h1 at `1.3rem` → 20px, h2 at `1.1rem` → 18px, body at `1rem` → 16px, meta at `0.9rem` → 14px.

**Only two weights:** 400 (regular) and 600 (semibold). The existing `font-weight: 500` in dashboard.html is replaced by 600 for consistency.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f8f8f8` | Page background (body) |
| Secondary (30%) | `#ffffff` | Card backgrounds, header bar, session containers |
| Accent (10%) | `#7a9e7e` | See reserved list below |
| Destructive | `#d73a3a` | Destructive actions only (none in this phase — included for completeness) |

**Accent (`#7a9e7e`) reserved for:**
1. Navigation links in header (`<a>` elements)
2. Answer prefix labels (`A:` in session replay)
3. Interest tags on child cards
4. Solid mastery dot colour on mastery map (see Mastery Colour Map below)
5. "Save changes" submit button background

**Supporting palette (informational — not accent):**
- Border: `#e0e0e0` — all card borders, header bottom border, turn dividers
- Muted text: `#888888` — timestamps, meta labels, "last practiced" dates
- Section label: `#555555` — h2 section headings
- Turn divider: `#f0f0f0` — between turns within a session card
- Session header background: `#f5f5f5` — collapsed session header stripe

**Mastery Colour Map (PARENT-02, D-08):**

| Bucket | Hex | Description |
|--------|-----|-------------|
| `not_started` | `#b0b0b0` | Grey dot — topic never touched |
| `fragile` | `#e6a817` | Amber dot — p_mastery < 0.5 |
| `in_progress` | `#4a90d9` | Blue dot — 0.5 ≤ p_mastery < 0.95 |
| `solid` | `#7a9e7e` | Green dot — p_mastery ≥ 0.95 |

Mastery dot: 10px × 10px circle, `border-radius: 50%`, `display: inline-block`. Source: 04-RESEARCH.md Pattern — mastery colour mapping.

**Alert Badge Colours:**

| Badge | Background | Text | Border |
|-------|------------|------|--------|
| `frustrated` | `#fff3cd` | `#856404` | `#ffc107` |
| `sensitive` | `#f8d7da` | `#721c24` | `#f5c6cb` |
| `new-interest` | `#d1ecf1` | `#0c5460` | `#bee5eb` |

Badge padding: `4px 8px`, `border-radius: 12px`, font-size: 14px (Label), font-weight: 600.

## Component Patterns

### Card

```
background: #ffffff
border: 1px solid #e0e0e0
border-radius: 12px
padding: 20px 24px   (1.25rem × 1.5rem)
```

Used for: child cards, session containers, alert rows.

### Accordion (Mastery Map)

Use native `<details>/<summary>` HTML — zero JS.

```html
<details class="subject-group">
  <summary class="subject-summary">
    <span class="subject-name">{Subject Name}</span>
    <span class="topic-count">{N} topics</span>
    <span class="subject-dots">{aggregate dot strip}</span>
  </summary>
  <ul class="topic-list">
    <li class="topic-row">
      <span class="mastery-dot" style="background: {bucket_color};"></span>
      <span class="topic-name">{Topic Name}</span>
      <span class="topic-date">{last practiced date or "never"}</span>
    </li>
  </ul>
</details>
```

All `<details>` closed by default (no `open` attribute). Parent clicks to expand the subjects they care about.

Summary padding: 12px 16px. Topic row padding: 8px 16px 8px 32px (32px left indent from summary). Alternating row background: `#f9f9f9` on odd rows.

### Form (Profile Editor)

Inline form at `/parent/children/{child_id}`. HTML form POST — no JS.

```
Input fields:    width: 100%, border: 1px solid #e0e0e0, border-radius: 6px, padding: 8px 12px, font-size: 16px
Select:          same as inputs
Checkboxes:      16px × 16px, gap: 8px between checkbox and label, display in flex-wrap row
Submit button:   background: #7a9e7e, color: white, border: none, border-radius: 8px, padding: 8px 24px, font-size: 16px, font-weight: 600, cursor: pointer
Form field gap:  16px between fields
Label weight:    600
```

### Login Page

Centred card layout. Max-width: 360px. Card padding: 32px.

```
Password input:  type="password", full width
Submit button:   "Sign in", full width, accent background (#7a9e7e)
No error message on failed login (D-04 — clean redirect, no feedback)
```

### Session Replay Turn Row

```
Turn container:     padding: 12px 20px, border-bottom: 1px solid #f0f0f0
Last turn:          no border-bottom
Q label:            "Q: " prefix, color: #888888, font-weight: 600
A label:            "A: " prefix, color: #7a9e7e, font-weight: 600
Question text:      font-weight: 600, color: #2c2c2c
Answer text:        font-weight: 400, color: #444444, font-size: 16px (Body)
Safety flag marker: 🚩 icon + "Flagged" text in #721c24, font-size: 16px (Body), appears inline after Q text
```

### Alert Feed Row

```
Row layout:         flex, align-items: center, gap: 12px, padding: 12px 16px
Timestamp:          14px, color: #888888, min-width: 120px
Child name:         14px, font-weight: 600
Badge:              see Alert Badge Colours above
Snippet:            14px, color: #444444, italic, max 80 chars, truncated with ellipsis
```

## Interaction States

### Accordion (`<details>/<summary>`)
- **Closed:** Arrow indicator points right (default browser `<details>` marker, or `▶` Unicode override)
- **Open:** Arrow points down; topic list visible with transition `max-height` or none (CSS `<details>` native animation is browser-provided)
- No JS required — native HTML behavior

### Form submit button
- **Default:** `#7a9e7e` background, white text
- **Hover:** `#6b8e6f` (5% darker), `cursor: pointer`
- **Disabled:** Not applicable — form always submittable (server validates)

### Alert badge
- Static — no hover/click interaction in Phase 4

### Session replay turn (safety flag)
- Static — 🚩 marker visible inline; no expand/collapse in Phase 4

### Navigation links in header
- Color `#7a9e7e`, no underline by default, underline on hover

## Accessibility

- All form inputs have associated `<label>` elements (explicit for/id linking)
- All `<input type="checkbox">` elements have visible text labels
- Colour is never the sole indicator of mastery — mastery dots supplement the bucket label (show label as `title` attribute on dot: `title="solid"`)
- Alert badges include accessible text (visible label text, not icon-only)
- `<details>/<summary>` is natively keyboard-navigable (Enter/Space to toggle)
- Login form: `autocomplete="current-password"` on the password input
- Page `lang="en"` set on all templates
